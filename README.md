# 桜川町 · Sakuragawa

> 花筏の流れる町 —— 一座漂着花筏的春日小镇

一个在浏览器里运行的 3D 开放世界漫游游戏。四月，桜川町的樱花开了：河水带着花瓣流过石砌护岸，小电车穿过油菜花田，傍晚五点的钟声响起后，河边的灯笼一盏一盏亮起来。

没有战斗，也没有倒计时。你可以沿着河散步，收集八处名所的御朱印，找到七只猫，和镇上的人聊聊天，或者只是在长椅上坐下来，看一天的光线慢慢流过。

**所有内容都是代码实时生成的**——地形、街道、两百多栋町屋与民居、三百多棵樱树、人物、猫、天空、水面，乃至筝与尺八的音乐、黄莺的叫声、道口的铃声，都没有使用任何图片或音频素材。

## 运行

需要 Node.js 18+ 与支持 WebGL2 的浏览器（Chrome / Edge / Firefox / Safari 新版）。

```bash
npm install
npm run dev      # 开发服务器，默认 http://localhost:5173
npm run build    # 生成 dist/，可部署到任意静态托管（相对路径）
npm run preview  # 预览构建产物
```

URL 参数（调试用）：`?q=low|medium|high` 指定画质，`?t=19.5` 指定开始时刻，`?fresh` 忽略存档，`?play` 跳过标题。

## 小镇里有什么

- **桜川并木道**：城中段的石砌运河，两岸樱花与提灯，河面漂着成团的花瓣（花筏），朱色太鼓桥上方挂着鲤鱼旗。
- **桜川神社**：山丘上的神社，十五座鸟居连成的石阶参道；可以参拜、净手、抽御神签、读绘马。
- **花雲寺 · 五重塔**：朱色的五重塔、钟楼（可以撞钟）与本堂。
- **本通り商店街**：二十多家町屋商铺——和果子、茶、旧书、团子、荞麦、酒屋……每家都有暖帘与招牌。
- **桜川駅**：每隔几分钟一列两节编组的小电车驶过，经过平交道口时铃声响起、栏杆落下。
- **千年桜**：田野中央的垂枝老樱。集齐八枚御朱印后，夜里它会为你点灯。
- 还有桜川中学校、桜ヶ丘公園（赏花的人们）、鏡湖与栈桥、竹林小径、灌满水的稻田与油菜花田。

## 玩法

- **御朱印**：八处名所设有御朱印台（立着「スタンプ」小牌），盖章后收入御朱印帐。
- **猫**：七只性格不同的猫，靠近按 E 摸摸它们；全部相识后，一只小猫会跟着你散步。
- **镇民**：十余位镇民，各有各的日常（扫地的巫女、钓鱼的老人、写生的画家、赏花的年轻人……）。
- **昼夜**：游戏里一小时约等于现实一分钟。黄昏、夜樱、黎明的光线各不相同；起风时会有「花吹雪」。
- **拍照模式**：自由移动镜头、调整时刻与滤镜，保存照片。
- 进度自动保存在浏览器本地。

## 技术

- 引擎：Three.js r180（WebGL2），Vite 构建，纯 JavaScript。
- 世界生成：扭曲网格地形（城镇 2 m 精度，向外几何级数放大到 2.6 km）、河岸相对的高度场、道路剖面压平、建筑地基、程序化屋顶（切妻、寄棟、入母屋）。
- 渲染：合批顶点色几何 + 单一着色器里的程序化图案（瓦、障子、格子、石板、窗……）；樱花树冠为花簇贴片 + 球形法线 + 逆光透光；GPU 草地、野花、地面花瓣与飘落花瓣（按樱花密度图分布）；自定义大气雾；Bloom 与调色后期；自适应分辨率。
- 人物与猫：基本体搭建并蒙皮到骨骼，程序化动画。
- 声音：Web Audio 实时合成——卡普拉斯-斯特朗算法的筝、尺八、黄莺/麻雀/云雀/乌鸦/青蛙、风与河、电车与道口、梵钟。

代码结构：

```
src/
  core/      数学与噪声、输入、声音、设置与存档
  render/    共享 uniform 与材质补丁、合批几何构建器、后期
  world/     布局规划、地形、水、道路与护岸、建筑与屋顶、地标、道具、树木、花瓣、铁路、天空
  entities/  角色骨骼与动画、玩家、镇民、猫
  game/      主循环、昼夜、镜头、文字内容
  ui/        界面、地图、御朱印与猫的手绘
```

# 黒髪の少女 · 程序化人物模型（`figure/`）

一个**完全由代码生成**的三维人物：黑长直、水手服的女高中生，日系二次元风格。没有任何贴图、扫描或建模软件导出的素材——头部、五官、头发、衣服、手、鞋都是数学曲面与生长算法算出来的。比例、发型与制服款式按用户提供的参考图（三视图与面部特写）调整：纤细的身形、及腰黑长直、齐眉刘海、短款白色水手服、膝上藏青百褶裙、黑色裤袜。

有两个精度档位：**2000 万档约 2203 万个三角面**（导出 GLB 的默认档位，导出脚本会检查不少于 2000 万），标准档约 426 万个三角面（查看器默认，浏览器里流畅）。

```bash
npm install
npm run figure          # 打开查看器 http://localhost:5173/figure/
npm run figure:build    # 构建静态查看器到 dist-figure/
npm run figure:export   # 在 Node 里生成 2000 万档并导出 GLB（dist-figure/kurokami-schoolgirl-ultra.glb，约 635 MB）
npm run figure:export -- --detail standard   # 标准档（约 120 MB）
```

查看器提供：全身 / 上身 / 面部 / 侧面 / 背面视角，「二次元」（赛璐璐两阶着色 + 描边）与「写实」（PBR）两种风格，「标准 / 2000万」两档精度，线框、自动旋转、面数构成，以及在浏览器中直接导出 GLB。URL 参数：`?view=face`、`?style=pbr`、`?detail=ultra`。

2000 万档在浏览器里生成约需 8–15 秒、占用约 1.5 GB 内存，适合独立显卡的电脑；手机请用标准档。

## 怎么「用代码捏」出来的

| 部分 | 方法 |
| --- | --- |
| 头与脸 | 一摞水平超椭圆截面放样（前额、颧骨、下颌、尖下巴各有关键帧），再叠加鼻梁、脸颊、嘴唇的位移场 |
| 五官 | 「贴花」投影到脸部曲面：眼睛是一张 120×84 的高密度网格，巩膜、虹膜渐变、瞳孔、两处高光全在顶点色里；眼线、睫毛、双眼皮、眉毛、嘴、腮红斜线是沿曲线的带状网格 |
| 头发 | 约 550 束发束 + 52 束刘海 + 18 束侧发 + 约 870 根细发丝；2000 万档再在每束表面铺 30 多根细发丝（共约 2.1 万根），颜色与法线沿用发束表面，整体仍是成束的二次元头发，近看是一丝一丝的。每束从头皮上的发根出发，按「重力 + 发流方向 + 碰撞（头、耳后发量、脖子、肩、上衣）」逐步生长，再扫掠成两侧内卷、末端收尖的扁平截面；头顶烘焙了一圈错落的天使环 |
| 水手服 | 上衣是前后不对称的截面放样；大翻领由内外两条轮廓线之间的直纹面投影到衣身上，白色饰线按「到外缘的距离」绘制；胸当、樱花徽记、红色蝴蝶结（结、两个圈、燕尾飘带）、藏青袖口 |
| 百褶裙 | 28 道刀褶：截面半径叠加一段缓升、陡降的锯齿，褶深从腰部向裙摆逐渐打开，内外两层加裙摆包边 |
| 手、腿、鞋 | 手掌放样 + 按关节弯曲的手指管；裤袜腿带小腿肚与膝盖的截面变化；乐福鞋有鞋口、饰带、U 形缝线与鞋底 |
